# ATK Token Intelligence Magazine — Desk Specification v1

Every desk must use the same operating contract so output is comparable and reusable.

## Required desk fields
- Desk name
- Core question
- Primary audience
- Permanent subtopics
- Preferred formats
- Mandatory angles
- Evidence requirements
- Lab/Benchmark triggers
- Distribution channels
- KPIs
- Escalation path

## 01 Token Intelligence
Core question: Where do Agents spend or waste tokens, and how can that be improved without unacceptable quality loss?
Subtopics: token accounting, compression, caching, prompt/context overhead, tool-result overhead, price movement, cost per successful task.
Mandatory angles: Token, Cost, Quality, Routing, ATK Verify.
Lab trigger: any savings claim that could materially influence engineering or commercial messaging.

## 02 Agent Intelligence
Core question: What do Agents and Agent builders repeatedly need?
Subtopics: runtime, workflows, autonomy, retries, failure modes, tool use, multi-agent patterns, operational demand.
Mandatory angles: Agent Demand, Performance, Reliability, Business.

## 03 MCP Intelligence
Core question: How is MCP changing tool connection, discovery, state, gateway and execution economics?
Subtopics: Remote MCP, Stateful MCP, tool discovery, tool schema overhead, gateways, permissions, security.
Mandatory angles: MCP, Token, Security, Routing, Trust.

## 04 A2A Intelligence
Core question: How will Agents communicate, delegate, coordinate and transact?
Subtopics: discovery, delegation, handoff, identity, authorization, protocol interoperability.
Mandatory angles: A2A, Trust, Security, Agent Economy.

## 05 Routing Intelligence
Core question: Which model should handle which task, and how should that choice be measured?
Subtopics: cost routing, quality routing, fallback, escalation, routing receipts, model substitution risk.
Mandatory angles: Routing, Cost, Quality, Trust, ATK.

## 06 Skill Intelligence
Core question: Which reusable Agent capabilities are useful, growing and worth learning from or integrating?
Subtopics: Agent Skills, Claude/Codex Skills, developer/media/enterprise skills, registries, packaging.
Mandatory angles: Developer, Agent Demand, Growth, Integration.

## 07 Framework Intelligence
Core question: Which frameworks and SDKs matter, for what workload, and at what tradeoff?
Subtopics: orchestration, state, tool use, memory, evaluation, provider abstraction.
Mandatory angles: Architecture, Developer, Performance, Lock-in, Routing.

## 08 Context & Memory
Core question: How should Agents manage context, memory and retrieval economically and reliably?
Subtopics: compaction, compression, retrieval, caching, memory architectures, context decay.
Mandatory angles: Token, Quality, Performance, Agent Demand.

## 09 Trust & Security
Core question: How can users verify what an Agent did and safely control it?
Subtopics: measurement, audit, integrity, permissions, identity, policy, security testing, Trust Receipts.
Mandatory angles: Trust, Security, Governance, Measurement.

## 10 Agent Economy
Core question: How should Agent work be priced, budgeted, billed and governed economically?
Subtopics: payments, billing, budget, wallets, x402/AP2, procurement, unit economics.
Mandatory angles: Cost, Business, Trust, Agent Unit Economics.

## Shared editorial rule
A desk does not own truth. It owns framing and domain expertise. Evidence state remains under ATK Verify. Experiments remain under ATK Lab. Product decisions remain under the Decision Ledger and Engineering gates.
