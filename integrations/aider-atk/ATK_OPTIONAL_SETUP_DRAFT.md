## 換端點就是換三個環境變數
```bash
export OPENAI_API_BASE="<端點的 API 根位址>"
export OPENAI_API_KEY="<你的金鑰>"
export AIDER_MODEL="openai/<模型名>"
```

沒有要裝的外掛，沒有要改的設定檔，沒有我們的程式跑在中間。**要換回去就是把這三個值改回去**，沒有任何東西會留下來。

## 三個最容易錯的地方（我們量過，不是猜的）
1. **根位址 vs 完整路徑。** `OPENAI_API_BASE` 要給根位址。我們錄到實際請求是 `/v1/chat/completions`——路由是底層自己接的。你自己再接一次就會變成 `/v1/chat/completions/chat/completions`。
2. **模型前綴。** `AIDER_MODEL` 要寫 `openai/<模型名>`，但送到端點的是**去掉前綴**的那個名字。所以端點那邊要認得的是後半段。
3. **三個值要一起到位。** 少一個就先停，別讓它跑起來再猜哪裡錯。

`check_config.py` 這三種都會指出來，而且**不連網**、不轉送任何東西、永遠不印金鑰或金鑰片段。它只看形狀——形狀對了不代表端點會回應。

## 金鑰
只進環境變數。不要放命令列（會進 shell 歷史，也會出現在 `ps` 裡），不要寫進專案檔案，不要貼進任何對話。

## 一件你該先知道的事
aider 啟動時會去 `raw.githubusercontent.com` 抓模型價格表，**而且加了 `--no-analytics --no-check-update` 也一樣**。這跟換不換端點無關，是 aider 本身的行為，但如果你的環境不能對外，你會先撞到這個。
