## Findings

### P1：模型前綴檢查會 false pass

**後果：** Quick Start 明說未使用 `openai/` 前綴會 exit 3，但目前只檢查是否含任意斜線。`anthropic/model` 會 exit 0 並顯示 Shape looks right，可能將請求導向非預期 provider。

**證據：** exact-head `check_config.py` 條件為 `if "/" not in model`。我用 `anthropic/model` 獨立執行，得到 exit 0。

**必要修正：** 僅接受 `openai/<非空模型名>`；為 `anthropic/model`、`openai/` 與 bare model 增加負測試。文件與實際 exit 保持一致。

**驗證：** 原 8 項加新負測試全過，並直接執行三個反例均 exit 3。

### P2：無網路結構測試的敘述過強

**後果：** PR body／EVIDENCE 稱任何 HTTP client 日後都會被 import test 擋下，但只允許 `os`、`sys` 不能阻止 `os.system("curl …")` 或相似路徑。這會把現在的 source inspection 誇大成未來的強制安全邊界。

**證據：** `test_it_makes_no_network_call` 只解析 import 集合；目前 `check_config.py` 經逐行檢視確實沒有連網行為。

**必要修正：** 在 executor response 與 EVIDENCE 將結論縮為「目前原始碼無網路呼叫；import 測試只作低成本回歸提示，不是網路隔離或完整防護」。不為此新增 sandbox、HTTP interception 或框架。

**驗證：** review 新 head 的文字與 source；既有測試仍全過。

### P2：外部使用報告缺直接來源

**後果：** 草稿公開後，讀者無法直接核對兩份外部第一手敘述，不符合本研究線的來源可追溯要求。

**證據：** `AIDER_WHAT_WE_LEARNED.md` 只有 Chrissy LeMaire／Sem Sinchenko 與日期，沒有 URL。

**必要修正：** 補上既有研究使用的兩個直接來源 URL，保留「個人經驗、非受控比較」界線，不新增效果主張。

**驗證：** URL 指向原作者文章，日期及主張與文章相符。

main 固定 deadline 為 `2026-09-25T18:30:00Z`，executor response 寫 `2026-09-25T19:20Z`。本結果在原期限前已建立，不影響本輪交付，但 revision 2 必須沿 reviewer 新訊號的 deadline，不得自行延長。
