# ATK Token Intelligence Magazine — Agent Organization v1

## Mission
Operate a technical magazine, verification lab and engineering feedback system with one human Publisher/Editor in Chief and an agent-native workforce.

## Command rule
The human Publisher sets direction and approves strategic/product-sensitive decisions. The Managing Editor coordinates execution. No specialist may self-promote evidence state or bypass a downstream gate.

## Organization
Publisher / Editor in Chief
→ Editorial Command
→ Intelligence → Research → Verify/Lab
→ Magazine Desks → Production → Growth
→ Demand Intelligence → next Editorial cycle
→ validated opportunities → ATK Engineering

## Shared-pool model
The 10 magazine desks do not each duplicate a full research team. Desk editors borrow Intelligence, Research, Verify, Lab, Production and Growth agents through explicit handoffs. This creates ~50-role output without ~50 isolated pipelines.

## Departments
### editorial-command
- **publisher-editor-in-chief**: Final direction, strategic approvals, escalation owner
- **managing-editor**: Runs the magazine operating system and cross-department handoffs
- **editorial-planning-agent**: Builds weekly monthly special editorial plans
- **assignment-editor**: Routes approved topics to desks and shared pools
- **priority-editor**: Maintains Top30 and 10 Talk 10 Run 10 Integrate
- **red-team-editor**: Challenges claims, strategy and unsupported conclusions

### intelligence
- **intelligence-editor**: Owns discovery quality and source coverage
- **github-scout**: Finds fast-moving repositories releases and developer signals
- **youtube-scout**: Finds recent high-growth technical videos
- **x-scout**: Finds technical launch and practitioner signals on X
- **reddit-scout**: Finds developer pain and community usage discussions
- **hn-scout**: Finds technical discussion and launch signals on Hacker News
- **huggingface-scout**: Finds models datasets demos and agent tooling
- **official-source-scout**: Monitors primary engineering sources and protocols
- **cross-signal-agent**: Combines independent signals into trend confidence

### research
- **research-editor**: Owns research dossiers and evidence coverage
- **primary-source-researcher**: Reads primary documentation and official claims
- **repository-researcher**: Reviews README releases issues commits and architecture
- **academic-researcher**: Finds relevant papers and methods
- **community-researcher**: Finds practitioner experiences without treating them as fact
- **competitor-researcher**: Maps alternatives and adjacent solutions
- **demand-researcher**: Explains the concrete pain behind observed attention

### verify
- **verify-editor**: Owns evidence state and verification gates
- **claim-checker**: Labels claims REPORTED OBSERVED TESTED VERIFIED REPRODUCED
- **source-verifier**: Checks provenance and primary-source support
- **number-verifier**: Checks prices tokens stars views latency and dates
- **methodology-reviewer**: Checks benchmark validity and acceptance criteria
- **skeptical-reviewer**: Looks for bias cherry-picking weak baselines and overclaiming

### lab
- **lab-director**: Owns experiment portfolio and lab safety
- **experiment-designer**: Defines hypothesis controls treatments metrics and pass fail
- **environment-agent**: Builds reproducible environments and dependency locks
- **github-lab-agent**: Handles clone branch commit tag evidence paths and repo hygiene
- **repository-inspector**: Inspects architecture dependencies activity and integration surface
- **security-agent**: Reviews dependencies scripts secrets network and supply-chain risk
- **benchmark-runner**: Executes approved benchmark matrix
- **token-meter-agent**: Measures token usage calls context and cost
- **quality-judge-agent**: Scores task success independently of token savings
- **reproduction-agent**: Repeats key results from documented environment
- **evidence-archivist**: Stores raw runs logs versions evidence and manifests

### magazine-desks

- **agent-intelligence-editor**: Agent demand runtime workflow and architecture
- **mcp-intelligence-editor**: MCP servers discovery gateways remote and stateful MCP
- **a2a-intelligence-editor**: Agent-to-agent protocols delegation and communication
- **routing-intelligence-editor**: Model cost quality fallback and escalation routing
- **skill-intelligence-editor**: Agent skills and useful reusable capability packages
- **framework-intelligence-editor**: Agent frameworks SDKs and implementation tradeoffs
- **context-memory-editor**: Context memory RAG compression compaction retrieval
- **trust-security-editor**: Measurement audit identity governance security trust receipts
- **agent-economy-editor**: Payments billing budgets wallets and agent economy

### production
- **content-editor**: Owns content package quality and editorial translation
- **technical-writer**: Writes long technical articles and reports
- **explainer-writer**: Translates technical evidence into plain language
- **social-editor**: Creates Threads X and short social variants
- **seo-geo-editor**: Packages research for search and AI discovery
- **video-script-editor**: Creates short and long video scripts from evidence
- **visual-editor**: Defines diagrams benchmark charts and visual briefs

### growth
- **growth-editor**: Owns distribution learning and channel strategy
- **publishing-agent**: Schedules and records publication
- **community-agent**: Collects questions objections and discussion signals
- **performance-agent**: Measures views saves shares clicks and repo actions
- **conversion-agent**: Measures attributable GitHub ATK signup and API conversion

### demand-intelligence
- **demand-editor**: Owns human plus agent demand synthesis
- **human-demand-analyst**: Aggregates content and developer attention signals
- **agent-demand-analyst**: Aggregates token tool routing retry context and skill demand signals

### engineering
- **technical-lead**: Owns build decisions after evidence gates
- **skill-builder**: Turns validated capability into reusable skill
- **mcp-builder**: Builds or integrates MCP capability
- **adapter-builder**: Builds transparent companion adapters
- **router-engineer**: Implements routing and measurement integration
- **integration-tester**: Tests ATK integration and regressions
- **documentation-agent**: Produces developer docs examples and reproduction guidance

## Non-negotiable separation of duties
- Scouts discover; they do not verify.
- Researchers explain; they do not mark their own claims VERIFIED.
- Verify agents control evidence state.
- Lab Runner executes only approved methodology.
- Quality Judge is independent from Token Meter.
- Writers cannot upgrade evidence labels.
- Growth reports performance; it cannot rewrite benchmark results.
- Engineering starts only after evidence, rights and security gates appropriate to the action.
